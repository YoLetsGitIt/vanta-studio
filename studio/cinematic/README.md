# Cinematic concept imagery

Generated using the built-in imagegen tool on 26 September 2026. These depict a fictional tattoo studio; they are not photographs of a customer location.

- `entrance-{640,960,1536}.webp`: approved reception/entrance concept.
- `interior-{640,960,1536}.webp`: companion workspace concept, generated using the entrance as a reference.

Originals, exact prompts and implementation notes: `design/studio-cinematic-direction.md` at the repository root.

Sharp resized the original PNGs to the stated widths and encoded WebP at quality 86. The largest pair is approximately 420 KB. No semantic image edits were made during conversion.

Used only in `/design/studio-cinematic.html`. The scroll effect scales and crossfades stills; a continuous camera walk requires an authored animation or filmed footage.
